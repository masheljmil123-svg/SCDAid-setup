Developer / safety-oriented validation harness

Prototype validation only. This page runs synthetic checks against the educational SCDAid prototype. It does not prove clinical safety, effectiveness, or correctness for real patients. Real clinical validation would require retrospective/prospective data, independent expert review, and appropriate ethical and regulatory oversight.

Scope: Client logic is exercised via app.js (window.__SCDAidValidationHooks). Additional mirrors in scdaid-validation.js reproduce small fragments of app.js (e.g. validate, criticalFlags) strictly for assertions — production code is not altered by this harness. SCAIA rows call POST /chat on the current origin; use a local Flask server so results are not skipped. On the main app, numeric SpO2 flows through collectSpo2InputState() inside readInputs() when #spo2Input is present; this harness also injects SpO2 on synthetic objects to regression-test criticalFlags without the full form.
